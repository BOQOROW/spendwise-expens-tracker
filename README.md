# SpendWise

SpendWise is a simple expense tracker that helps you manage your monthly budget. You set your monthly income, add your expenses, and the app shows your total income, total expenses and remaining balance.

## Features

- Set your monthly income in KSh
- Add expense items with a name and an amount
- See total income, total expenses and remaining balance on the dashboard
- Get a message telling you how much money you have left
- Dark dashboard layout with a sidebar for navigation

## Built With

- HTML
- CSS
- JavaScript

## Project Files

- `index.html` - the page structure
- `style.css` - the styling
- `script.js` - the app logic
